# A Subdomain-Aware Stacked Logistic-Regression Classifier for Self-Reported Doctor-Diagnosed Diabetes in Adults

## Overview

This research implementation trains independent domain-specific logistic-regression models and combines their outputs with a logistic-regression orchestrator. SHAP explains the orchestrator's output, and a rule-based explanation agent turns those explanations into text; no generative language model is used. The target is self-reported doctor-diagnosed diabetes (`DIQ010`).

## Research-use-only disclaimer

This software is for research and demonstration only. It is not a clinical diagnostic tool, risk model, prevalence estimate, causal model, or validated decision-support system. The target is self-reported doctor-diagnosed diabetes (`DIQ010`); model outputs are not clinical diagnoses and must not be used to make clinical decisions.

## Data

The NHANES 2017–2018 public data and documentation are available from the [CDC NHANES continuous survey](https://wwwn.cdc.gov/nchs/nhanes/continuousnhanes/default.aspx?BeginYear=2017). The included raw XPT files are in `nhanes_2017_2018/raw/`; together they occupy about 31 MiB. `prepare_nhanes.py` merges the selected data by respondent ID and creates the adult analysis CSV. The outcome is self-reported doctor-diagnosed diabetes (`DIQ010`). The prepared dataset and model are included.

The synthetic benchmark is artificial and contains no real individuals. No synthetic CSV is included or generated by this repository. The authors must obtain and provide the CSV, including its source and license:

Name the file `Diabetes_and_LifeStyle_Dataset.csv`. The app searches for it in the repository root or `data/`; the synthetic training command below uses `data/`. The CSV must contain these columns (including the target):

`Age`, `bmi`, `waist_to_hip_ratio`, `hypertension_history`, `cardiovascular_history`, `systolic_bp`, `diastolic_bp`, `heart_rate`, `cholesterol_total`, `hdl_cholesterol`, `ldl_cholesterol`, `triglycerides`, `glucose_fasting`, `glucose_postprandial`, `insulin_level`, `hba1c`, `family_history_diabetes`, `physical_activity_minutes_per_week`, `diet_score`, `smoking_status`, `alcohol_consumption_per_week`, `screen_time_hours_per_day`, `sleep_hours_per_day`, `income_level`, `education_level`, `employment_status`, `gender`, `ethnicity`, `diagnosed_diabetes`.

## Installation

From the repository root in PowerShell, create and activate a virtual environment and install the pinned dependencies:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

## Usage

Run commands from the repository root. Prepare the NHANES data and train its model with:

```powershell
python prepare_nhanes.py
python train_nhanes_model.py
```

After obtaining the synthetic CSV described above and placing it at `data\Diabetes_and_LifeStyle_Dataset.csv`, train the synthetic model with:

```powershell
python train_model.py --data "data\Diabetes_and_LifeStyle_Dataset.csv"
```

Launch the Streamlit app with:

```powershell
streamlit run app.py
```

The app loads the included model artifacts. The synthetic CSV is needed for synthetic model training and the app's synthetic research visualizations; it is not generated by `train_model.py`.

## Known limitation

The orchestrator is trained on in-sample domain-model predictions rather than out-of-fold predictions. This can make its training inputs more optimistic than the predictions it receives for unseen data.
